# AGENTS.md

## Диктовка пользователя (важно)

Пользователь часто вводит текст голосом через speech-to-text. Из-за этого появляются
артефакты распознавания. Ключевые:

- **«Спуль»** — это не имя, не название и не обращение. Это артефакт диктовки фразы
  «сделай git pull» (или «спул»). Просто выполните `git pull`.
- Обрывки типа «ты прав», «слышишь», «блять» — голосовой мусор, не команды и не
  утверждения. Не отвечайте на них и не цитируйте их в мыслях/выводах.
- Если фраза варварски звучит как обращение по имени («X — сделай ...»), где X —
  не известная сущность проекта (спуль, спул, пул и т.п.), считайте её командой
  после артефакта диктовки, а не именем агента. Агента зовут не «Спуль».
