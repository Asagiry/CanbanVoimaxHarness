# kill-ai-slop: Руководство по устранению визуального и текстового шаблонного шума

Скилл предназначен для выявления и полного удаления характерных шаблонных признаков генеративного интерфейса (AI slop) в веб-приложениях, стилях Tailwind CSS и пользовательских сценариях.

---

## 1. Базовые принципы визуальной чистоты

1. **Обоснованность каждого элемента**: Любое визуальное решение должно иметь функциональную причину, а не служить декорацией пустоты.
2. **Один доминантный акцент, одна тональность**: Запрещено смешивать несвязанные спектры (фиолетовый, индиго, бирюзовый) в одном представлении.
3. **Иерархия за счет масштаба и отступов**: Читаемость интерфейса строится на типографических размерах и плотности сетки, а не на раскрашивании каждого слова и постоянной смене гарнитур.
4. **Первичность вычитания**: Устранение лишних рамок, теней и плашек предшествует добавлению новых стилей.
5. **Смысловая нагрузка индикаторов**: Бейджи, иконки и статусные точки являются навигационными маркерами, а не заполнителями пространства.

---

## 2. Каталог характерных маркеров шаблонности

### 2.1 Цветовые градиенты и размытия
- **Маркер**: Переходы индиго-фиолетовый (`from-indigo-500 to-purple-600`), фоновые градиентные пятна со сверхвысоким размытием (`blur-3xl`), радужные окантовки карточек.
- **Норма**: Монохромный нейтральный фон, один акцентный тон для ключевого действия, четкие 1px разделители.

### 2.2 Градиентный текст заголовков
- **Маркер**: Использование `bg-clip-text text-transparent bg-gradient-to-r`.
- **Норма**: Сплошной высококонтрастный цвет шрифта (`#171717` на светлом фоне, `#f0f6fc` на темном), акцент за счет начертания и размера.

### 2.3 Избыточное скругление и парящие тени
- **Маркер**: Карточки с `rounded-3xl`, гигантские тени `shadow-2xl shadow-indigo-500/20`, стекломорфизм (`backdrop-blur-md bg-white/10`).
- **Норма**: Сдержанные скругления (`rounded-lg` или `rounded-md`), плоские границы (`border border-border`), тени только у всплывающих контекстных меню и модальных окон.

### 2.4 Инфляция бейджей и статусов
- **Маркер**: Каждое второе слово обернуто в пилюлю (`rounded-full px-2 py-0.5`), мерцающие индикаторы статуса с анимацией `animate-ping` на некритичных элементах.
- **Норма**: Текстовые метки без цветных подложек, статичные индикаторы только для реальных процессов выполнения или сетевой активности.

### 2.5 Перегрузка эмодзи и generic-иконками
- **Маркер**: Использование эмодзи в заголовках колонок, кнопках и карточках задач; цветные подложки для иконок (`bg-blue-100 text-blue-600 rounded-lg p-2`).
- **Норма**: Строгие векторные пиктограммы Lucide монохромного оттенка без цветных квадратов под ними.

## 3. Инструменты сканирования

В состав скилла входит утилита статического анализа кода:

```bash
# Запуск проверки кодовой базы
node .agents/skills/kill-ai-slop/scripts/scan.mjs src/

# Машинный вывод для автоматической обработки
node .agents/skills/kill-ai-slop/scripts/scan.mjs src/ --json
```

Игнорирование преднамеренных решений оформляется комментариями:
- `// deslop-ignore` — пропуск всей строки
- `// deslop-ignore-next-line 06` — пропуск конкретного правила для следующей строки

## 4. Паттерны трансформации компонентов

### Кнопка действия
- **До**: `bg-gradient-to-r from-violet-600 to-indigo-600 shadow-lg shadow-indigo-500/30 text-white rounded-full px-6 py-3 hover:scale-105 transition-all`
- **После**: `bg-[#238636] hover:bg-[#2ea043] text-white text-xs font-medium rounded-md px-3 py-1.5 transition-colors`

### Контейнер карточки
- **До**: `bg-white/80 backdrop-blur-xl border border-white/20 rounded-2xl p-6 shadow-xl relative overflow-hidden before:absolute before:inset-0 before:bg-gradient-to-br before:from-indigo-500/10`
- **После**: `bg-[#161b22] border border-[#30363d] rounded-md p-3`

### Выделение метрик
- **До**: `text-4xl font-extrabold bg-gradient-to-r from-purple-400 to-pink-600 bg-clip-text text-transparent animate-pulse`
- **После**: `text-lg font-mono font-semibold text-[#f0f6fc] tabular-nums`
