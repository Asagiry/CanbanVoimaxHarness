## 💎 2. Что было сделано и исправлено за эту сессию

Все работы выполнены по стандарту NASA Ground Truth Sensor, проверены компиляторами и ревьюерами L2 и влиты в `main`:

### 1. 🪟 Решена системная ошибка «WebView2Loader.dll не найден» (`CVH-RELEASE-BUILD-FIX`)
- **Проблема**: При сборке под Windows с тулчейном GNU (`x86_64-pc-windows-gnu`) библиотека `WebView2Loader.dll` компилируется динамически (160 КБ) в `src-tauri/target/.../release/`. Ранее в папку `Release/Windows/bin/` копировался только `.exe`, из-за чего Windows блокировала запуск системным алертом.
- **Решение**:
  - Создан `src-tauri/nsis-hooks.nsh`: установщик NSIS автоматически упаковывает `WebView2Loader.dll` и распаковывает его в `$INSTDIR` рядом с программой.
  - Скрипты `build-release.ps1` и `build-release.bat` автоматически копируют и `canban-voimax-harness.exe`, и `WebView2Loader.dll` в `Release/Windows/bin/`.
  - В `Release/Windows/installer/` собран готовый установщик `CanbanVoimaxHarness_0.1.0_x64-setup.exe` (5.68 МБ).

### 2. 📋 Виджет To-dos переведён в парящий оверлей-поповер (`CVH-TODO-OVERLAY-FIX`)
- **Проблема**: Ранее раскрывающийся план To-dos занимал статическое место в потоке документа, сжимал и сдвигал чат вверх, а также создавал двойные серые полосы-разделители над полем ввода.
- **Решение**:
  - `TaskTodoWidget` переведён в абсолютный поповер (`absolute bottom-full mb-2 left-0 z-30 shadow-xl rounded-xl`).
  - При открытии список задач парит **поверх** чата, вообще **не сдвигая** ленту сообщений.
  - Удалена внешняя полоса-разделитель (`border-t border-[#ebebeb] bg-[#fafafa]`).
  - Триггер встроен в тулбар инпута в виде аккуратной пилюли с бейджем `X/Y` и пульсирующей точкой при активном выполнении.

### 3. 🔍 Новый Git Diff: аккордеон файлов и скрытие мусора (`CVH-UI-DIFF-THINKING-POLISH`)
- **Проблема**: В сайдбаре Git Diff отображались сырые служебные заголовки гита (`diff --git a/... b/...`, `index ...`, `--- /dev/null`, `+++ b/...`), а весь дифф шёл сплошным неразделимым текстом.
- **Решение**:
  - Сайдбар перестроен в интерактивный **аккордеон файлов**: каждый изменённый файл выведен отдельной строкой со статусом (`M`, `A`, `D`) и счётчиками дельт (`+X -Y`).
  - Клик по файлу раскрывает дифф **строго под ним**, повторный клик сворачивает. Добавлены кнопки «Развернуть всё» и «Свернуть всё».
  - Весь мусорный шум гита отфильтрован: отображаются только полезные строки с чанками `@@ ... @@`, зелёными добавлениями (`+`) и красными удалениями (`-`).

### 4. ⌨️ Посимвольный вывод рассуждений («Typewriter Thinking»)
- В `ThinkingCard.tsx` добавлен плавный 60 FPS посимвольный рендеринг (`requestAnimationFrame` с адаптивным шагом). Мысли агента плавно печатаются в реальном времени с пульсирующим курсором `▋` и живым секундомером, создавая эффект живого размышления без скачков текста. Для уже завершенных тернов текст отображается мгновенно без задержек.
