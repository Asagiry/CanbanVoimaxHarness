## 💎 2. Что было сделано за вечер (Все 8 масштабных фичей влиты в `main`)

Всё сделано параллельным роем субагентов в изолированных ворктри, прошло ревью и проверено сенсорами:

### 1. 🖼️ Плавающий блок ввода чата (по референсу) + Прикрепление картинок
- **Интерфейс ввода**: Стильная тёмная плавающая карточка (`rounded-2xl bg-[#1e1e20] border border-[#2e2e32] shadow-xl`) с авторесайзом многострочного поля.
- **Внутренний тулбар**:
  - Круглая кнопка **`+`** для файлов и изображений.
  - Пилюля статуса **`🛡️ Full access ⌵`** с переключением режима тулов.
  - Селектор модели (`gemini-3.8-flash-high ⌵`).
  - Круглая кнопка: белый квадрат **Стоп** (при выполнении) / синяя стрелка **Отправить** (в покое).
- **Картинки в чате**: Добавление по клику на `+`, Drag-and-Drop или вставкой из буфера (<kbd>Ctrl</kbd>+<kbd>V</kbd>) с полосой миниатюр перед отправкой.
- **Обложки карточек Канбана**: Перетаскивание картинки прямо на карточку на доске устанавливает обложку задачи в стиле Linear/Trello. Также доступно через ПКМ-меню карточки (*«📷 Прикрепить обложку...»*).

### 2. 📊 Телеметрия перенесена вниз
- Показатели кэша, TPS и кольцо контекста убраны из правого верхнего угла шапки.
- Размещены в изящную моноширинную строку статуса под блоком ввода:  
  `⏱️ {turns} шагов · {tps} tok/s  |  💾 {tokens} tok · Кэш {cacheHitRate}%  |  ○ {contextPercent}%`
- При наведении на кольцо контекста всплывает поповер с разбивкой токенов и кнопкой быстрого сжатия (*«Компактировать»*).

### 3. 🔍 Встроенный правый сайдбар Git Diff в чате задачи
- **Двухколоночный интерфейс дровера**:
  - Слева: Хронологическая лента диалога и плавающее поле ввода.
  - Справа: Интерактивная панель **Git Diff (440px)** прямо в консоли задачи (по нарисованному наброску!).
- **Возможности**:
  - Список изменённых файлов ворктри со статусами (`M`, `A`, `D`) и дельтами (`+add -del`).
  - Просмотр диффа с номерами строк, цветной подсветкой добавлений (+) и удалений (-), чанк-заголовками `@@` и копированием патча в буфер в 1 клик.
  - Автоматическое живое обновление при вызовах тулов и завершении задачи.
  - Кнопка сворачивания панели в компактный вертикальный рейл (44px).

### 4. 🪟 Безрамочное окно Frameless + Кастомные кнопки управления
- В `tauri.conf.json` отключена системная чёрная рамка Windows (`"decorations": false`).
- Верхняя панель снабжена `data-tauri-drag-region` (окно свободно и плавно перетаскивается за шапку).
- Двойной клик по свободной области разворачивает/восстанавливает окно на весь экран.
- Кастомные тактильные кнопки в правом верхнем углу:
  - **Свернуть** (`—`)
  - **Развернуть / Восстановить** (`▢` / двойной квадрат)
  - **Закрыть** (`✕`) с фирменным красным ховером (`hover:bg-rose-600`).

### 5. 🎨 Строгий монохромный дизайн Vercel & ChatGPT (0% Color Slop)

### 6. 🔄 10 реконектов к LLM API и чистая цель задачи (Prompt)
- Цикл повторных попыток подключения до **10 раз** с нарастающим интервалом (10с, 20с, 30с ... 100с) при сбоях сети или HTTP 5xx с выводом текста ошибки в скобках:  
  `[Связь с LLM API недоступна (причина ошибки). Повторная попытка X/10 через Yс...]`
- Карточка *«Цель задачи / Prompt»* в шапке больше не засоряется служебными строками `[USER]: ► Продолжай` — указания человека живут в контексте диалога, а исходная цель задачи остаётся нетронутой.

### 7. ⚡ Автономные пользовательские скрипты на колонках (`.bat`, `.ps1`, `.py`, `.sh`)
- В настройках колонок (`PipelineColumn`) добавлено поле `on_enter_script` (`onEnterScript`).
- При перемещении задачи в колонку (например, из Backlog в Разработку) система автоматически исполняет заданный скрипт (создание git worktree, подготовка окружения) до старта агента.
- Поддерживаются Python-скрипты (`.py`), PowerShell (`.ps1`), Batch (`.bat`) и Shell (`.sh`).
- Передаются системные переменные: `CVH_TASK_ID`, `CVH_WORKTREE_PATH`, `CVH_BRANCH`, `CVH_STAGE_ID`, `CVH_BOARD_ID`.
- Настройка скрипта доступна прямо из контекстного меню шапки колонки по ПКМ.

### 8. 🗂️ Доски, контекстное меню по ПКМ и чистка репо

## ⚠️ 4. Срочный баг для починки на работе (Белый экран в чате)

> **🚨 КРИТИЧЕСКИЙ БАГ (ЧАТЫ / БЕЛЫЙ ЭКРАН):**  
> При клике на карточку задачи на доске вместо нормального тёмного чата открывается **сплошной белый прямоугольник** (см. скриншот в истории).  
> **Анализ причин:**  
> 1. В `src/components/drawer/AgentConsoleDrawer.tsx` на строке 750 и 920 захардкожены светлые классы:  
>    `bg-white text-[#171717]` и `bg-[#fafafa]`. На фоне тёмного обсидианового приложения это режет глаз белым оверлеем.  
> 2. Кроме того, возможен **React Runtime Crash** (белый экран смерти React) из-за незащищенного чтения свойств в одном из новых компонентов: `GitDiffSidebar`, `ContextGauge` или при рендере вложений картинок.  
> **Что сделать утром первым делом:**  
> 1. Открыть dev-консоль (F12 / Webview DevTools) и посмотреть точный React stack trace ошибки.  
> 2. Обернуть дровер в `<ErrorBoundary>`.  
> 3. Перевести все контейнеры `AgentConsoleDrawer.tsx` с `bg-white / bg-[#fafafa]` на единый тёмный кибер-стиль: `bg-[#09090b] / bg-[#121214] border-[#27272a] text-zinc-100`.
