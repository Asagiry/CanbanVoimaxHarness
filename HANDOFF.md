### 📝 Текст отчёта advance_task прямо в «Ответе агента»
- **Что было**: агент в течение 4 минут составлял подробный аудит-отчёт с тестами в параметре `summary` тула `advance_task`, но в «Ответе агента» выводилась сухая системная строчка:

В блоке **«✨ Ответ агента»** отображается **полный красивый Markdown-отчёт** со всеми чек-листами и результатами проверок!

### ⚙️ Исправление команд Windows (python -c и кавычки)
- **Причина бага**: Rust `Command::args` на Windows экранировал двойные кавычки как `\"`, а `cmd.exe` этот слэш не понимает и передавал питону буквально. Из-за этого `python -c \"print(1)\"` выполнял пустой бэкслеш (печатал пустоту с exit code 0) или падал с `SyntaxError: unterminated string literal`.
- **Решение**: `run_scoped_command` в `src-tauri/src/agent.rs` переведён на `cmd.raw_arg("/D /S /C ...")`. Кавычки не искажаются, `python -c "print(1)"` честно выводит `1` в `stdout` (проверено модульным тестом `test_execute_command_windows_quoting_python` ✅).
- **Честный статус ошибки**: в `ToolExecutionCard.tsx` при `exitCode !== 0` теперь отображается красный `[X] failed (код 1)` вместо обманчивой зелёной галочки.
